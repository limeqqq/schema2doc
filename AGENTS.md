# Rules for OpenCode Agent
- Язык разработки: Python 3.10+.
- Принцип: Zero external dependencies для ядра и SQLite (только стандартная библиотека: sqlite3, dataclasses, argparse, typing).
- Тестирование: каждый созданный модуль должен сопровождаться тестами на pytest или unittest.
- Стиль кода: строгая типизация (Type Hints), docstrings, обработка ошибок без падений по необработанным исключениям.
- Формат вывода: не писать весь проект монолитом — разделять по файлам согласно архитектуре.
